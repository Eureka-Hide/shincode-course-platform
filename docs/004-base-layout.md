# 004 — 基本レイアウト・ヘッダー

**Phase**: 1
**状態**: [完了]
**依存**: 003

## 概要
認証済みユーザー向けの共通レイアウトとヘッダーを実装する。
ヘッダーにはユーザーのアバター・名前、ログアウトボタン、管理者向けリンクを含める。
