# 005 — 動画リスト画面

**Phase**: 2
**状態**: []
**依存**: 004

## 概要
認証済みユーザーが全動画をカード形式で閲覧できる一覧画面を実装する。
各カードにはサムネイル・タイトル・説明・視聴進捗バーを表示する。

- [ ] `progress_percentage` に応じて表示を切り替え
